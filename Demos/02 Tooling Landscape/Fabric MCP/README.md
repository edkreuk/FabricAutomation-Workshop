# Fabric MCP

Microsoft ships two flavours of Model Context Protocol (MCP) servers for Fabric. Use them to expose Fabric capabilities to AI agents (Copilot, Claude, custom assistants, etc.).

## Local MCP (Pro-Dev)

Runs on your machine and is aimed at developer scenarios — building, debugging, and integrating Fabric into local AI tooling.

📖 [Get started with the local pro-dev MCP server](https://learn.microsoft.com/en-us/rest/api/fabric/articles/mcp-servers/pro-dev-local/get-started-local)

## Remote MCP (Core)

Hosted by Microsoft and reachable over the network — no local install required. Best for shared agents and production scenarios.

📖 [Get started with the remote core MCP server](https://learn.microsoft.com/en-us/rest/api/fabric/articles/mcp-servers/core-remote/get-started-core)
