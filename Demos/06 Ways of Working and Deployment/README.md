# Ways of Working and Deployment

The demos for this section live in a separate open-source project: **FabricOps**.

FabricOps is an accelerator for Microsoft Fabric ways of working and deployment - opinionated patterns, reusable building blocks, and end-to-end pipelines for getting Fabric workloads from dev to prod with confidence.

➡️ **[github.com/gronnerup/FabricOps](https://github.com/gronnerup/FabricOps)**

Head over to the repo for the demo content, samples, and documentation used in this part of the workshop.
