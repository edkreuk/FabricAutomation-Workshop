Microsoft Fabric Hands-on Workshop

🎯 Workshop Objective 

In this hands-on workshop you will build a metadata-driven data platform foundation in Microsoft Fabric. You will work with workspaces, lakehouses, notebooks, shortcuts, semantic models, reports, and variable libraries, following a Medallion Architecture approach. 

The labs are incremental. Each exercise builds on the previous one. 

 

✅ Prerequisites 

Before starting, make sure you have: 

Access to a Microsoft Fabric enabled tenant 

Permission to create and manage workspaces 

Access to Lakehouse, Notebook, and Power BI items 

A browser (Edge or Chrome recommended) 
Visual studio Code installed
